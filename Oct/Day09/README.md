# Day 9: In-place Swap


| Problem | Approach in Plain English | Time Complexity | Space Complexity |
|---------|---------------------------|-----------------|------------------|
| **Reverse String** (Primary) | Use two pointers from ends moving inward, swapping characters in-place using tuple unpacking. | O(n) | O(1) |
| **Reverse Words in a String** (Variant) | Tokenize words to strip extra spaces, then swap words from both ends inward using two pointers. | O(n) | O(n) |
| **Reverse Words in a String III** (Variant) | Convert string to a character array and swap characters of each word in-place between whitespace boundaries. | O(n) | O(n) |
